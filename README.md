# Featured Projects

## Cloud-Based Agentic AI Restaurant Customer Engagement System

**Final Year Project · Sponsored by Salesflo**

A production-oriented **agentic AI restaurant engagement platform** built around WhatsApp, supporting natural-language ordering, voice interaction, conversational memory, cart management, complaint workflows, receipts, and grounded responses.

### Architecture & Technologies

`Amazon Bedrock AgentCore` `Amazon Nova Pro` `Bedrock Guardrails` `Knowledge Bases`  
`Titan Text Embeddings` `ECS Fargate` `Lambda` `DynamoDB` `S3`  
`SQS` `API Gateway` `EventBridge` `Transcribe` `Polly` `CloudWatch`  
`ECR` `VPC` `IAM` `Secrets Manager` `CloudFormation`

### Highlights

- Agentic orchestration for multi-turn customer conversations
- WhatsApp text and voice interaction
- Retrieval-augmented grounded responses
- Persistent conversation memory
- Asynchronous voice-processing workflows
- PDF receipt generation
- Containerized AWS deployment
- CI/CD workflow
- Dedicated monitoring environment with **15 CloudWatch alarms**

## CloudOps Production Simulation Lab

A production-style AWS environment built to demonstrate **cloud engineering, infrastructure, deployment, security, monitoring, and troubleshooting** skills.

### Architecture

`Amazon EC2` `Nginx` `Node.js` `PM2` `Amazon RDS MySQL`  
`Amazon S3` `IAM` `CloudWatch` `VPC` `Terraform`

### Highlights

- Custom VPC with public and private subnets
- EC2 application server behind Nginx
- Private Amazon RDS MySQL database
- Private S3 object storage with signed URLs
- IAM role-based AWS access
- CloudWatch logs and custom metrics
- Database migration to RDS
- Infrastructure recreated using **Terraform**
- Security-group isolation between application and database tiers
